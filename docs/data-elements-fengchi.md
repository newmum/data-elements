# 风驰数据计算平台（data-elements-fengchi）

<a id="overview"></a>

## 工程定位

风驰是独立的中文数据库工作台前端，与仓库其他前端一样保留自己的 `package.json`、`package-lock.json`、Vite/TypeScript 配置、测试和 `dist/` 构建输出。无需启动或构建兄弟前端，也不依赖共享 Java 后端。本工程主文档只在此维护，入口见[根文档索引](../README.md#documentation)。

当前功能使用虚构样例数据和浏览器本地状态。界面参考连接树、多标签、表格、SQL 编辑器与结果面板的常见桌面工作流，品牌标识和工具图标为独立资源，不使用 Navicat 私有代码或商标素材。数据库产品标识来源及授权边界见[第三方资源](#third-party)。

## 安装、启动与构建

使用 Node.js 22.12 或更高版本。进入 `data-elements-fengchi/`，独立执行：

```sh
npm ci
npm run dev
```

浏览器打开 `http://localhost:3020/`。端口统一在 `vite.config.ts` 配置，开发和生产预览都使用 `3020`、`host: localhost`、`strictPort: true`。它与澄天 `3000`、海通 `3002`、IDAAS `3005`、万象 `3010`、云梯 `3030` 不冲突；端口已被占用时直接报错，不能自动悄悄换端口。开发与预览不要同时运行。

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`npm run check` 汇总单元测试和包含 TypeScript 检查的生产构建。`npm ci` 按本工程锁文件安装，仓库不增加根 Node workspace 或跨应用构建依赖。运行日志、截图和临时报告放在根 `logs/fengchi/`；依赖、构建结果、测试缓存和浏览器数据不提交 Git。

## 部署方式

将本工程 `dist/` 作为独立静态站点的根目录发布，资源基础路径为 `/`。当前不注册到主平台菜单，不共享登录会话，也没有反向代理或后端 API 配置。若以后改为二级路径部署，需要同步检查 Vite `base`、品牌图片、favicon 和页面中的静态资源地址，不能仅移动构建目录。

`npm run preview` 用于检查构建产物，不作为生产服务。实际发布使用原生静态服务器；不带入独立演示站点身份、托管配置或原仓库的 Git 元数据。

## 可操作功能

- 连接类型选择、配置检查、连接树、对象搜索与表切换。连接弹框不接收密码，配置检查不表示真实数据库网络测试成功。
- 数据、表单、结构、DDL 四个表视图。视图页签贴合既有导航和内容边界，去除独立小边框及内缩留白；选中、悬停使用主题底色区分，页签与表格之间保留连续分隔线。支持搜索、排序、分页与单条记录浏览。数据/表单视图的“数据筛选”支持字段、条件和值，多条件按 AND 组合，并可清除；不再使用仅针对 `status` 字段的下拉框。文本、数值、日期时间及 NULL 使用相应条件，非法值不能应用，筛选变化从第一页显示。
- 已有字段的名称、独立类型/长度、无符号、空值、主键、默认值和注释可编辑；各表结构草稿独立，应用/撤销与有效草稿的 DDL 高亮预览同步。
- 双击单元格编辑、Enter 确认、Esc 取消；新增、删除、应用、撤销和修改单元格黄色标记。表格上方不再单列操作状态；底部左侧依次为“应用更改”“撤销”和修改状态，数据视图右侧保留页码、总数和每页行数，窄内容区自动换行。表单/结构/DDL 同样保留底部应用入口。
- 当前页网格矩形拖选、边缘滚动、TSV 复制；清空选区与删除记录分开，主键和必填数值/日期禁止清空。
- 垃圾桶按显式选择删除整条记录：优先使用勾选行，否则使用所选单元格对应的行，表单视图使用当前记录。显示选中行数，确认框列出表名、数量与记录 ID；确认后仍是待应用修改，可在应用前撤销。切换页、排序或筛选时清除旧选择，避免误删之前的范围；页面初始化的字段信息高亮不等于删除选择。
- 可拖动弹框、可调整宽度的侧栏、多标签重排与关闭、浅色/深色主题。顶部导航行横向贯通，连接树搜索位于其下方，与中央数据/表单/结构/DDL 视图栏同高；该处不再重复显示新建连接和收起全部按钮，主工具栏及菜单中的连接入口保留。树名称始终单行，空间不足时省略，数字计数独立保留。左连接栏默认恢复 220px，右信息栏默认最小宽度 180px；两侧拖动或键盘调整分别保存，双击分隔条恢复各自默认值，不覆盖已有手动宽度。
- 导航页签栏右侧的加号后保留信息栏开关，左右开关箭头表示下一次收起或展开的方向。页签溢出时使用覆盖式轻量滚动条，悬停显示、移开隐藏，不占据额外高度；可拖动，也可用方向键/Home/End 调整。字段类型使用深浅主题适配的彩色细线图标：文本 T、数字 12、日期时间日历等。
- SQL 编辑器高亮、补全、可编辑空白行和独立查询结果；Ctrl/Command+Enter 执行，Ctrl/Command+S 保存。
- SQL 中双击选中当前数据库的完整表名，再右键可“查看表结构”，复用或打开对应表页签并切换到结构；查询内容和结果保留。支持 FROM/JOIN 等表引用位置、显式库名与完整标识符引号，不把同名列、别名、字符串或注释当作表。未知库表、歧义匹配、部分词、多选区和无法可靠解释的语法不显示入口。
- 本地 SQL 解析支持 SELECT 列或 `*`、WHERE 比较与 AND、ORDER BY、LIMIT、COUNT(*)、SHOW TABLES、DESCRIBE。JOIN、GROUP BY、子查询和写入语句明确拒绝。
- 字段结构与只读 DDL 预览、标准模板新表、查询历史，以及本地函数定义的新建、编辑、保存、复制和删除。
- 导出先打开确认框，可选择当前筛选结果、选中记录、当前页或忽略筛选的全部记录，并选择全部或前 N 条，以及 CSV、TSV、JSON 格式；执行查询后也可导出该查询结果。范围、可用数量、实际数量和文件名均在下载前显示，取消不会下载；当前页和筛选范围保持表格排序。

## 数据与接口边界

应用后的表数据、连接配置、已保存查询、函数定义与主题保存在当前浏览器；未保存草稿以页面会话为主。更换域名、端口、浏览器或清除本地存储不会自动迁移数据。菜单“编辑 → 重置数据”仅恢复当前浏览器的样例表数据。

结构视图不保留底部常驻说明区域，校验错误仅在发生时于字段表上方提示，查看 DDL 的入口保留。结构草稿在切换表和视图时保留，未应用草稿不保证刷新后保存；应用会先检查所有表草稿和当前记录，再一次性保存，任一校验失败不部分应用。全局撤销恢复已应用基线。有效草稿同步预览 DDL，无效草稿保留输入并提示错误，DDL 回退已应用定义。

这里没有真实数据库连接、数据库认证、SSH/SSL、事务或真实 SQL 执行。生成的 DDL 只反映前端字段定义，不是已执行的建表语句。结构编辑限已有字段属性，不增删字段、不建立索引/外键；`id` 用作当前记录标识，必须保留名称和非空整数类型。类型/长度与已有记录不兼容时拒绝应用，不静默截断或强制转换。校验是保守的本地兼容性检查，不替代真实数据库服务器的完整校验。不得把真实密码或密钥写入前端配置。

SQL 表名识别只查询当前本地 `commerce_db` 的字段目录，不建立网络连接，也不会执行所选 SQL。识别器有长度/词元/嵌套上限；CTE、表函数、三段式名称和其他不确定方言保持不显示跳转，不能将其视作完整 SQL 语法支持。

导出取打开确认框时的本地快照，包含已确认但尚未应用的记录修改；正在输入的单元格或表单草稿需先确认或取消。CSV/TSV 使用 UTF-8 BOM 和标准引号转义，NULL 输出为空单元格，可能被电子表格执行的文本公式前加单引号；JSON 保留 NULL 与数值类型。导出只生成浏览器下载文件，不上传、不请求真实数据库；数量不能超过所选范围，空范围不能下载。

当前读取、筛选、排序、分页、复制、批量清空、删除及导出均处理本地样例，不向业务服务发请求，不产生后端 SQL，也没有服务端租户授权域。新增真实接口时，必须遵守[批量查询与分页规范](data-elements.md#batch-pagination)，由可信会话确定租户并逐 ID 校验数据范围，不能沿用前端样例过滤作为权限控制。

## 验证与后续检查

单元测试覆盖 SQL 支持范围与错误输入、记录修改、弹框边界、左右侧栏默认尺寸和独立宽度持久化、底部应用/撤销状态及分页结构、树名称与计数分离、查询隔离与标签顺序、表单、DDL、主题品牌、字段类型图标和矩形选区，以及结构草稿、字段重命名的数据迁移、主键/NULL/精度/长度/默认值保护。表名右键测试覆盖引用位置、库名与引号、未知和歧义匹配、注释/字符串/列名排除，以及切换查询或修改 SQL 后的过期菜单保护。工程集成测试另行锁定项目/锁文件名称、开发与预览端口及严格占用检测配置，并对 20/100 行本地读取、TSV 复制和批量清空断言业务网络调用为零；无后端 SQL 调用。

数据工具测试覆盖类型适配的多条件筛选、精确数值比较、日期时间与 NULL、选择优先级、严格记录 ID、非破坏性删除、排序，以及导出快照、范围/数量校验、CSV/TSV/JSON 转义和公式文本保护。导航测试覆盖滚动条尺寸与偏移边界、完整导航布局和左右箭头状态。浏览器验收需同时检查筛选后编辑/撤销、删除确认/取消/撤销、排序后的分页导出，并实际读回下载文件核对字段、记录 ID 和数量。

界面验收应覆盖首次打开和刷新、数据/表单/结构/DDL 切换、查询页签反复切换、关闭/取消再打开、深浅主题，以及待应用编辑的应用和撤销。端口验证需确认首页、脚本和本地图标可加载，并确认重复启动在同端口失败而非占用其他应用端口。未完成跨浏览器、真实触屏设备或真实数据库执行的全面端到端验证。
