# 风驰数据计算平台（data-elements-fengchi）

<a id="overview"></a>

## 工程定位

风驰是独立的中文数据库工作台前端，与仓库其他前端一样保留自己的 `package.json`、`package-lock.json`、Vite/TypeScript 配置、测试和 `dist/` 构建输出。无需启动或构建兄弟前端，也不依赖共享 Java 后端。本工程主文档只在此维护，入口见[根文档索引](../README.md#documentation)。

普通独立模式保留原有虚构样例及本地编辑能力；共享 Mock 模式从元数据平台读取同一份场景状态及现有接口，不读取旧 `commerce_db` 或另存业务数据。界面参考连接树、多标签、表格、SQL 编辑器与结果面板的常见桌面工作流，品牌标识和工具图标为独立资源，不使用 Navicat 私有代码或商标素材。数据库产品标识来源及授权边界见[第三方资源](#third-party)。

## 安装、启动与构建

使用 Node.js 22.12 或更高版本。进入 `data-elements-fengchi/`，独立执行：

```sh
npm ci
npm run dev
```

浏览器打开 `http://localhost:3020/`。端口统一在 `vite.config.ts` 配置，开发和生产预览都使用 `3020`、`host: localhost`、`strictPort: true`。它与澄天 `3000`、海通 `3002`、IDAAS `3005`、万象 `3010`、云梯 `3030` 不冲突；端口已被占用时直接报错，不能自动悄悄换端口。开发与预览不要同时运行。

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`npm run check` 汇总单元测试和包含 TypeScript 检查的生产构建。`npm ci` 按本工程锁文件安装，仓库不增加根 Node workspace 或跨应用构建依赖。运行日志、截图和临时报告放在根 `logs/fengchi/`；依赖、构建结果、测试缓存和浏览器数据不提交 Git。

共享演示使用 `npm run dev:mock`，仍为 3020；元数据平台先在原 3000 端口运行 `pnpm run dev:mock` 并登录，再从左上角 Logo 的全局导航同页进入风驰。`.env.mock` 的 `VITE_METADATA_BASE_URL` 指向元数据平台，`VITE_MOCK_ENABLED=true` 选择共享模式。`npm run build:mock` 输出根 `logs/mock/fengchi/dist/`。两种模式切换需停止当前前端，不另换端口。共享模式首次直接新开浏览器窗口时可能没有模拟会话，此时通过返回入口登录；不自动创建或放宽会话。

## 部署方式

普通构建的 `dist/` 作为独立静态站点根目录发布，资源基础路径为 `/`。元数据平台全局导航中的风驰入口由 `VITE_FENGCHI_BASE_URL` 指定，开发默认原 3020、部署默认 `/fengchi/`；风驰顶部提供返回元数据平台首页的入口。若使用二级路径，仍需同步检查 Vite `base`、品牌图片、favicon 和静态资源地址。共享 Mock 的两端须在可信部署地址运行，正确配置元数据平台地址和风驰 origin；不能把普通静态包视为已接入真实后端。

`npm run preview` 用于检查构建产物，不作为生产服务。实际发布使用原生静态服务器；不带入独立演示站点身份、托管配置或原仓库的 Git 元数据。

## 可操作功能

- 连接类型选择、配置检查、连接树、对象搜索与表切换。连接弹框不接收密码，配置检查不表示真实数据库网络测试成功。
- 数据、表单、结构、DDL 四个表视图。视图页签贴合既有导航和内容边界，去除独立小边框及内缩留白；选中、悬停使用主题底色区分，页签与表格之间保留连续分隔线。支持搜索、排序、分页与单条记录浏览。数据/表单视图的“数据筛选”支持字段、条件和值，多条件按 AND 组合，并可清除；不再使用仅针对 `status` 字段的下拉框。文本、数值、日期时间及 NULL 使用相应条件，非法值不能应用，筛选变化从第一页显示。
- 已有字段的名称、独立类型/长度、无符号、空值、主键、默认值和注释可编辑；各表结构草稿独立，应用/撤销与有效草稿的 DDL 高亮预览同步。
- 双击单元格编辑、Enter 确认、Esc 取消；新增、删除、应用、撤销和修改单元格黄色标记。表格上方不再单列操作状态；底部左侧依次为“应用更改”“撤销”和修改状态，数据视图右侧保留页码、总数和每页行数，窄内容区自动换行。表单/结构/DDL 同样保留底部应用入口。
- 当前页网格矩形拖选、边缘滚动、TSV 复制；清空选区与删除记录分开，主键和必填数值/日期禁止清空。
- 垃圾桶按显式选择删除整条记录：优先使用勾选行，否则使用所选单元格对应的行，表单视图使用当前记录。显示选中行数，确认框列出表名、数量与记录 ID；确认后仍是待应用修改，可在应用前撤销。切换页、排序或筛选时清除旧选择，避免误删之前的范围；页面初始化的字段信息高亮不等于删除选择。
- 可拖动弹框、可调整宽度的侧栏、多标签重排与关闭、浅色/深色主题。顶部导航行横向贯通，连接树搜索位于其下方，与中央数据/表单/结构/DDL 视图栏同高；该处不再重复显示新建连接和收起全部按钮，主工具栏及菜单中的连接入口保留。树名称始终单行，空间不足时省略，数字计数独立保留。左连接栏默认恢复 220px，右信息栏默认最小宽度 180px；两侧拖动或键盘调整分别保存，双击分隔条恢复各自默认值，不覆盖已有手动宽度。
- 导航页签栏右侧的加号后保留信息栏开关，左右开关箭头表示下一次收起或展开的方向。页签溢出时使用覆盖式轻量滚动条，悬停显示、移开隐藏，不占据额外高度；可拖动，也可用方向键/Home/End 调整。字段类型使用深浅主题适配的彩色细线图标：文本 T、数字 12、日期时间日历等。
- SQL 编辑器高亮、补全、可编辑空白行和独立查询结果；Ctrl/Command+Enter 执行，Ctrl/Command+S 保存。
- SQL 中双击选中当前数据库的完整表名，再右键可“查看表结构”，复用或打开对应表页签并切换到结构；查询内容和结果保留。支持 FROM/JOIN 等表引用位置、显式库名与完整标识符引号，不把同名列、别名、字符串或注释当作表。未知库表、歧义匹配、部分词、多选区和无法可靠解释的语法不显示入口。
- 本地 SQL 解析支持 SELECT 列或 `*`、WHERE 比较与 AND、ORDER BY、LIMIT、COUNT(*)、SHOW TABLES、DESCRIBE。JOIN、GROUP BY、子查询和写入语句明确拒绝。
- 字段结构与只读 DDL 预览、标准模板新表、查询历史，以及本地函数定义的新建、编辑、保存、复制和删除。
- 导出先打开确认框，可选择当前筛选结果、选中记录、当前页或忽略筛选的全部记录，并选择全部或前 N 条，以及 CSV、TSV、JSON 格式；执行查询后也可导出该查询结果。范围、可用数量、实际数量和文件名均在下载前显示，取消不会下载；当前页和筛选范围保持表格排序。

## 数据与接口边界

共享模式目录为“实际组织机构 → 数据源 → 表/视图 → 对象”，机构父子关系与元数据平台一致；中间不插入应用系统层。机构和数据源一次批量读取，选中一个数据源时读取一次表目录和详情；字段按用户首次打开的表读取，页码、每页行数、名称筛选、字段条件及排序交给同一个分页预览接口。20/100 行每次只新增一次预览请求。表与视图采用相同 tableId、字段定义及预览处理器，示例视图为基础表的有效记录子集。当前共享模式只开放结构和数据读取，不执行 SQL 或记录/结构写入；独立模式的本地编辑功能继续保留。共享模式导出仅提供已读取的当前页及其显式选择，不将当前页冒充全部数据。

共享状态位于元数据平台 origin 的专用 Mock 存储，由只读 iframe 桥调用现有接口；风驰只持有页面显示结果，不复制场景或保存第二份业务基线。父子窗口双向核对 origin/source，按 nonce 关联请求，不在 URL、响应或风驰存储中传递认证 token、角色或连接凭据。每个字段/预览请求均由元数据平台按当前模拟租户、角色范围及表关联数据源校验，不能靠风驰树隐藏节点代替授权。源码及契约规则见[Mock 契约同步](data-elements.md#mock-contracts)。

| 能力 | 复用的元数据接口 |
| --- | --- |
| 当前租户与组织 | `GET /portal/sso/session`、`POST /sym/org/getOrgTree` |
| 组织下数据源 | `POST /dst/db/stats` 的 `orgApps/datasources` |
| 数据源及表/视图目录 | `POST /dst/db/srcdetail`、`GET /dst/db/tables` |
| 字段结构 | `GET /dst/db/fields`，携带 `tid/snapshotOnly` |
| 分页数据 | `POST /dst/db/preview`，携带同一 `tableId` |

以下本地编辑、SQL 和样例说明适用于普通独立模式；共享模式以以上只读范围为准。

应用后的表数据、连接配置、已保存查询、函数定义与主题保存在当前浏览器；未保存草稿以页面会话为主。更换域名、端口、浏览器或清除本地存储不会自动迁移数据。菜单“编辑 → 重置数据”仅恢复当前浏览器的样例表数据。

结构视图不保留底部常驻说明区域，校验错误仅在发生时于字段表上方提示，查看 DDL 的入口保留。结构草稿在切换表和视图时保留，未应用草稿不保证刷新后保存；应用会先检查所有表草稿和当前记录，再一次性保存，任一校验失败不部分应用。全局撤销恢复已应用基线。有效草稿同步预览 DDL，无效草稿保留输入并提示错误，DDL 回退已应用定义。

这里没有真实数据库连接、数据库认证、SSH/SSL、事务或真实 SQL 执行。生成的 DDL 只反映前端字段定义，不是已执行的建表语句。结构编辑限已有字段属性，不增删字段、不建立索引/外键；`id` 用作当前记录标识，必须保留名称和非空整数类型。类型/长度与已有记录不兼容时拒绝应用，不静默截断或强制转换。校验是保守的本地兼容性检查，不替代真实数据库服务器的完整校验。不得把真实密码或密钥写入前端配置。

SQL 表名识别只查询当前本地 `commerce_db` 的字段目录，不建立网络连接，也不会执行所选 SQL。识别器有长度/词元/嵌套上限；CTE、表函数、三段式名称和其他不确定方言保持不显示跳转，不能将其视作完整 SQL 语法支持。

导出取打开确认框时的本地快照，包含已确认但尚未应用的记录修改；正在输入的单元格或表单草稿需先确认或取消。CSV/TSV 使用 UTF-8 BOM 和标准引号转义，NULL 输出为空单元格，可能被电子表格执行的文本公式前加单引号；JSON 保留 NULL 与数值类型。导出只生成浏览器下载文件，不上传、不请求真实数据库；数量不能超过所选范围，空范围不能下载。

当前读取、筛选、排序、分页、复制、批量清空、删除及导出均处理本地样例，不向业务服务发请求，不产生后端 SQL，也没有服务端租户授权域。新增真实接口时，必须遵守[批量查询与分页规范](data-elements.md#batch-pagination)，由可信会话确定租户并逐 ID 校验数据范围，不能沿用前端样例过滤作为权限控制。

## 智能问数（本机试用）

工具栏「历史」右侧的「智能问数」提供中文生成 SQL、解释 SQL、检查潜在错误三个入口。默认自动关联当前表及已加载结构，切换表时同步；没有明确表时提示用户选择。只处理发送前展示并经用户确认的表结构，以及面板中展示的需求和 SQL；不自动读取表格行数据。共享 Mock 模式沿用现有授权后的表结构，不另建 schema 数据源。每次发送前须确认内容可能包含 SQL 字面值，清除敏感信息；回复按纯文本展示，复制后由人审核，不自动插入或执行。

这是默认关闭的本机技术适配服务，不是公开生产服务。Vite 在 `http://localhost:3020` 将 `/api/ai` 转到仅监听 `127.0.0.1:3021` 的 Node 服务。仅接受这个 Origin 与本机 Host；没有远程用户认证，禁止将该适配端口暴露外网。生产集成应由正式后端提供会话鉴权、权限校验、持久配额与审计。静态构建及 `vite preview` 不包含此适配器。

在工程目录分别启动 `npm run ai:server` 和 `npm run dev`。Node.js 需支持内置 `fetch`（建议 Node 22 LTS 或更新受支持版本）。服务端由安全环境配置以下值，不使用 `VITE_` 前缀，不放进前端文件、Git、截图或日志：

- `FENGCHI_AI_ENABLED=true`：显式开启。
- `OPENAI_API_KEY`：用户自己的 OpenAI API 密钥，仅服务端读取。
- `OPENAI_MODEL`：用户账户可用且明确选定的模型；不自动选价更高的模型。
- `FENGCHI_AI_MAX_REQUESTS`：本次服务进程的调用上限，整数 1 至 1000。

缺少任何配置即拒绝请求，不消耗额度。确认模型、可用额度、到期时间与预算后再启用；该请求数上限不是金额硬上限，服务重启会重置。每次上游尝试都计数，包括失败和取消，无自动重试。每次最多 2000 输出 token，60 秒超时，最多 20 张表 / 300 个字段、4000 字需求与 12000 字 SQL。用户取消会中止等待，但已开始的调用仍可能计费。输入按白名单组装，禁止附带表格行数据字段。

上游固定为 OpenAI 官方 Responses API，`store:false`，不配置工具，不执行数据库操作，不支持用户自定义目标 URL或重定向。`store:false` 不意味着服务商零保留；应遵守账户的数据处理政策。说明文档：https://developers.openai.com/api/reference/resources/responses/methods/create

验证：`npm run test:ai` 使用假上游覆盖默认关闭、来源校验、结构白名单、请求限制、返回文本与失败脱敏，不产生任何真实 API 消费。前端契约测试随 `npm test` 执行。实际账户连通性和浏览器交互须在安全配置及用户授权后另验，不能用 Mock 测试冒充真实接口验证。

## 可视化模型（浏览器编排原型）

顶部工具栏「视图」右侧的「模型」打开占满浏览器内容区域的沉浸式编辑器，返回查询后可再次进入，保留本次页面会话中的模型，不影响查询页签。界面采用点阵画布、带输入输出端口的节点和箭头连线。左侧算子库与右侧选中节点属性均可独立收起、展开；顶部开关始终保留。底部预览／信息面板可收起、展开，并通过上边缘拖动调整高度，也支持键盘调整。左侧算子可拖入画布，已有节点可移动；在右侧节点配置中选择前序节点完成连接。

模型消费当前工作区已经加载的表结构与记录，或用户主动选择的本地 CSV／JSON／风驰表格 XML 文件；文件只在浏览器处理，不上传。不单独复制业务样例、不请求真实数据库或 OpenAI。共享 Mock 模式沿用父工作区授权后的表及当前页数据，不能将预览视作全库计算结果。筛选、字段选择、关联、聚合与输出均为浏览器内计算；模型脚本展示的是编排定义，而非已执行的 SQL。保存导出模型定义，不导出记录或凭据。

本阶段用于审阅编排交互，不提供真实任务调度、数据库写入或持久执行记录。页面刷新后需重新编排，下载文件不等于模型已部署。运行前检查节点参数、前序连接与循环；超出原型的数量上限应明确报错，不静默执行部分结果。

### 算子目录与调整尺寸

算子库按业务类别列出并支持中文名称、英文关键词和说明搜索。目录区分输入／输出连接器与处理算子；可运行项支持点击及拖入画布，尚未接入执行器的项目显示「仅配置」，可以拖入、配置与连线，但运行按钮禁用；下游尝试运行也明确拒绝，不会静默透传或伪造成功。当前 77 项目录中，56 类支持浏览器 Mock，21 项提供配置界面但不能执行。可运行范围包括输入及预览、字段投影重命名、筛选排序去重限量、内关联及查找、集合合并交差、存在性匹配、有限笛卡尔积、分组聚合、类型转换、常量和安全四则派生、空值替换、字面替换、首尾空白处理、字段拆解拼接、间隔采样、序号、末尾保留脱敏、密集排名、累计求和、逆透视、UTC 日期分量、JSON 自有路径标量提取、标量序列化、质量断言、按输入顺序偏移、全局分位数、单组数值求和透视、分隔符行拆分、JSON 标量数组展开与条件分支预览。它们均只在浏览器中处理已加载记录，不代表已接入生产引擎。

分类参考 [Azure Data Factory 转换目录](https://learn.microsoft.com/en-us/azure/data-factory/data-flow-transformation-overview)、[Apache Hop 转换目录](https://hop.apache.org/manual/latest/pipeline/transforms.html)、[Apache NiFi 组件目录](https://nifi.apache.org/components/) 与 [Apache Flink Table API](https://nightlies.apache.org/flink/flink-docs-stable/docs/dev/table/tableapi/)。这是针对风驰场景归纳的覆盖清单，不声称穷尽所有平台能力。连接器、函数、调度属于不同层次，不以数量混算为已经实现的算子。

节点右下角可拖动调整尺寸，连线锚点随尺寸变化；左右栏边缘可拖动调整宽度，关闭后重新打开保留会话内宽度，双击边缘恢复默认。尺寸受上下限与视口限制，节点尺寸随模型 JSON 导出；侧栏宽度不作为模型逻辑。底部面板继续支持独立高度调整。

### Mock 精确语义与限制

“字段派生”仅支持字段与常量的四则运算，不执行表达式脚本；“字符串处理”当前仅去首尾空白。间隔采样是确定性的每 N 行取一行，不冒充随机样本；排名为全局单字段密集排名，偏移和累计均按输入顺序，不代表实时窗口。日期分量使用严格 ISO UTC；JSON 提取仅遍历自有属性并返回标量，不执行路径脚本。分位数忽略空值并按线性插值返回一行。断言失败阻止预览，不自动删行修正。

数据库、消息、HTTP 等外部连接器仍未接入；真实流处理、水位线、窗口任务、任意脚本、SQL 引擎及外部写出均不可用。仅配置项禁止执行，不生成假运行结果。当前限制 30 个节点、1000 行、200 列；每项配置 10000 字符、单元格 100000 字符、单节点 200 万字符、整个模型 800 万字符资源预算；错误、溢出、循环、重名、缺少配置均应显式报错，不绕过验证。以后接入生产执行器仍须后端鉴权、成本限制、持久化与真实数据一致性验证。

透视仅支持一个分组字段、一个透视键与一个数值求和字段，动态列名带 `pivot:` 前缀；行拆分保留 NULL 为一行，JSON 数组展开的 NULL 和空数组为零行。条件分流只预览用户选定的真／假分支，不假装支持两个物理输出端口。

未完成项分两类：任意格式解析及未实现的流程行为仍需专门适配，不应笼统称为必须后端；真实数据库／HTTP／对象存储／Kafka／CDC、实时窗口、水位线、流限速与持久缓存等需要受控连接器或执行器。当前目录的这些项目提供仅配置界面，运行禁用，不代表已接通。

### 本地文件、匹配与摘要

CSV／JSON／XML 输入节点由用户主动选择本地文件（最大 2 MB、1000 行、200 列）。CSV 使用首行字段名并保留文本；JSON 为标量对象数组；XML 仅支持风驰表格交换格式，不是任意业务 XML。XML 格式为 `<table><columns><column name="id"/></columns><rows><row><field name="id" type="number">1</field></row></rows></table>`，拒绝 DTD、外部实体、CDATA 等。JSON／XML 内数字与 NULL 可保留。导入记录只驻留当前浏览器会话，模型定义不嵌入文件内容，刷新后需重新选择文件。

CSV／JSON／XML 输出节点先模拟预览，再由用户明确点击“下载已预览结果”保存本地文件，不写远端系统。CSV 对可能成为表格公式的字符串加单引号，避免公式注入；这是有意的安全转换，不冒充字符串完全无损。保存模型与下载结果是两个独立操作。

SHA-256 节点对 UTF-8 字符串生成标准摘要，NULL 保留；不是加密、密码 KDF 或经过 FIPS 验证的安全模块。XML 字段提取仅从上述交换格式取指定行／自有字段。模糊匹配采用大小写敏感、最大距离 0–3 的有界 Levenshtein 最近匹配，等距多候选明确报错，不猜测。代理键为前缀与业务字段 JSON 的确定性编码，重复或 NULL 业务键报错，不声称数据库主键已写入。增删改只添加 `_action` 一类标记，不执行增删改。

正则校验是全字符串匹配的安全子集：字面字符、点、`\d`／`\w`／`\s`、`?`／`*`／`+`；不支持分组、或、回溯、任意 JavaScript 正则。模式与输入有长度／运算预算，未支持语法显式拒绝。它不等同完整正则引擎。

### 受限 Excel 与 Parquet 本地文件

Excel／Parquet 输入输出使用动态加载的本地解析模块，不连接外网服务。依赖固定为 ExcelJS 4.4.0、hyparquet 1.33.0、hyparquet-writer 0.18.0 与 fflate 0.8.3；运行时不下载脚本。范围是有限体量、平面标量测试数据，不承诺任意工作簿或任意压缩 Parquet 兼容。

参考实现文档：[ExcelJS](https://github.com/exceljs/exceljs)、[hyparquet](https://github.com/hyparam/hyparquet)、[hyparquet-writer](https://github.com/hyparam/hyparquet-writer)、[fflate](https://github.com/101arrowz/fflate)。文件读取仍需用户主动选择，输出仍需先预览再显式下载；模型定义不包含导入文件内容。

依赖审计记录：新增依赖生产审计报告 `exceljs → uuid` 的 2 项 moderate 关联告警（同一根因），无 high／critical。对应 [GHSA-w5hq-g745-h8pq](https://github.com/advisories/GHSA-w5hq-g745-h8pq) 为 v3／v5／v6 在传入外部 buffer 时的边界问题；本版本 ExcelJS 源码及浏览器包仅调用无参数 `uuidv4()`，不走受影响入口。本项目不声称告警已消除，不用覆盖 package 版本假装修复浏览器内置包；后续升级须重新审计与回归。


XLSX 读取第一张工作表，其他工作表也先做安全预检；拒绝公式、宏、外部链接、媒体和复杂单元格。真实流式展开受单条 4 MB／总计 8 MB／100 条 ZIP 条目限制，不信任 ZIP 声明尺寸；行列坐标必须规范且位于允许范围内。Parquet 仅接收平面文本／有限数字／NULL、UNCOMPRESSED、PLAIN 数据页，拒绝压缩、字典编码及嵌套结构；Thrift、页范围和定义层级 RLE／bitpacked 在库解码前检查。两种格式输入输出仍限 2 MB、1000 行、200 列。受限兼容范围在失败时明确报错，不退回不安全解析。

### 前端配置覆盖与执行边界

全部 77 项现在都可搜索、拖入和配置，其中 56 项可在有限记录上执行浏览器 Mock；另 21 项只提供属性、连线与定义导出：HTTP／Kafka／CDC／对象存储输入、目录监听、时态维表、四类实时窗口、广播／异常路由／限流／缓存／脚本／SQL／合流、数据库／HTTP／Kafka／对象存储输出。配置可保存，但不会发请求、创建连接、执行脚本或写入数据库。输入类无前序要求；维表／合流可选两个前序。选择仅配置节点时预览禁用；运行其他节点而上游含仅配置节点时会报错，不用模拟数据冒充执行结果。属性中不设置密码／密钥字段，且提示不得填写秘密。

这些节点还需要真实执行器、连接器、权限与持久化接入，才能称为真实系统功能。前端配置完成不等于后端计算或外部服务已接通。

建模画布使用深浅主题自适应的细点阵，按视口固定 20px 间距显示，缩放节点时点阵不缩小消失；仅作视觉参考，不代表节点自动吸附。
