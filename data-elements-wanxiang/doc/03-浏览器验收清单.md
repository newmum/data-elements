# 3.2.0 联网环境浏览器验收清单

先安装并完成 `npm run check`、`npm run typecheck`、`npm run build`；不要使用 --force 掩盖依赖问题。启动后逐项验收：

| 场景 | 通过条件 |
|---|---|
| 收起/展开菜单 | 图标在侧栏几何中心；收起无竖线，展开保留；19个图形不重复 |
| 键盘与提示 | Tab、上下、Home/End可定位菜单；焦点可见，收起项显示中文Tooltip |
| 18个业务页 | 对应标题、业务描述、三项亮点、独立插画及主操作；无乱码/重叠 |
| 浅深主题 | 顶部、导航、页头、卡片、表头/固定列、浮层统一，没有白色残片 |
| 数据源标识 | 8种来源符号各异；表格/抽屉/ER对象库与节点一致 |
| 来源编辑 | 业务域、责任人、业务系统、环境、说明保存刷新不丢失；新来源统计0 |
| 配置检查 | 改连接信息后检查失效；只改业务归属保持检查；停用后编辑仍停用 |
| 筛选与批量 | 类型/状态/业务域/已采集筛选有效，重置还原；批量结果逐项说明 |
| 来源详情 | 概览、对象、采集历史可切换；已采集计数进入对应来源目录 |
| 采集与模型 | 检查配置→选表→采集→目录→加入模型→全屏ER→保存刷新；不调用后台 |
| 来源下拉操作 | 采集主按钮、更多详情/目录/检查/编辑/停用各自正确，不截断菜单 |
| 审核与对标 | 申请人显示姓名；定义来自冻结版本；完整ID在详情/提示；对标仍引用实际修订 |
| 全屏ER | 所有入口覆盖浏览器视口；字段拖线、复合键、选中、推荐、布局、关闭返回正常 |
| 工单复检 | 未改本地记录时仍失败；更改记录后复检通过才能关单 |
| 数据兼容 | 原3.1数据、布局与关系保留；属性增量补全不覆盖已有编辑 |
| 响应式 | 1920/1670/1440/1366/768/390，桌面125%和150%，表格仅内部滚动 |
| 极端内容 | 超长中文/英文来源名、长schema、IPv6、无负责人、空工作区、超过一页数据 |
| 错误保护 | 配额不足、备份格式错误、取消表单、连续保存、旧请求晚到均不误报成功 |

这是待执行的真实应用验收清单，不能因隔离DOM检查通过就全部勾选为通过。
