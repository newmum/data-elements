## 浏览器截图到底验证了什么

`tests/review/render-components.cjs` 读取当前TSX组件和真实本地Mock种子。原生DOM部分（Page、ProductNavigation、SVG图形、字段列渲染、描述和业务数据）来自当前源码；React Hooks和Ant Design组件由明确的隔离适配器替代。然后用Chromium加载项目CSS及这些DOM，测量位置和截图。

这些是**源码DOM样式评审图，不是完整React/Ant应用运行图**。未使用AI图片冒充运行截图；也不能据此声称真实Dropdown、Select、Tooltip、全屏路由、拖线和React状态更新全部验收通过。

384组组成：18页 ×（6种尺寸收起 + 4种桌面尺寸展开）× 2主题 = 360组；登记与详情抽屉 × 6尺寸 × 2主题 = 24组。尺寸为1920×1080、1670×1060、1440×1000、1366×900、768×1024、390×844。审核、对标和标准落地在最后一轮内容优化后重新执行了60组，最终统计仍为384个不同场景，不重复累加为更多“页面”。

检查页面横向溢出、指定主容器边界、标题/描述字号、页头文字与操作重叠、装饰加载、收起菜单图标中心、选中线按状态切换、深色顶部和抽屉页脚。可见收起导航中心与64px侧栏中心差不超过1px（实测0.5px来自边框）。移动端隐藏侧栏不计为可见中心验收。

## 复现

```bash
npm install
npm run check
npm run typecheck
npm run build
npm run dev
```

依赖齐全后，优先执行真实页面验收。隔离样式检查另需 Python Playwright 与 Chromium：

```bash
npm run review:dom
python tests/review/review.py --screenshots
```

上述工具和原始输出随包提供。`doc/validation/checks.log`、`source-dom-review.json`、`build-attempt.log`、`registry-access.log`分别为本轮实际结果。旧版135/260项记录不作为本版新执行结果混入。
