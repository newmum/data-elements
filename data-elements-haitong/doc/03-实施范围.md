# 设计说明书与本轮实现范围

原设计文档在basis目录保留原文，其中火山橙方向已由用户后续要求替换为海蓝，再在本轮调整为深海钴蓝。其余未实现能力不通过改写原文来隐藏。

| 设计领域 | 本轮实现 | 边界 |
|---|---|---|
| 主题/视觉 | 12模块矢量场景、浅深主题、字体统一、导航收起、加载/骨架/减少动效 | 隔离样式检验，不是完整应用视觉验收 |
| 向导任务 | 五步、表字段映射、EXACT/TRIM/UPPER/LOWER、APPEND/UPSERT、发布版本 | 来源是已有本地样例，不能登记真实连接；无任意SQL执行 |
| 画布 | X6节点端口、属性、历史、复制、多选、布局、全屏保存 | 运行器只识别支持的单链路和跨网配对结构；未实现任意NiFi流程兼容 |
| 任务登记 | 支持本工程Flow导出、外部ID去重、校验后登记 | 未支持NiFi各版本原生导出格式和远程纳管 |
| 批量 | 同名/前后缀匹配、固定相位、串行创建、成败、重试 | 浏览器可见时本地推进，不是后台服务器服务 |
| 多表 | 同一任务内多映射、逐表写入结果 | 失败重试是基于当前发布版的新运行，不是任意检查点分片重放 |
| 运维 | 运行/表详情、阶段、日志、取消、重跑 | 全部本地记录；无真实心跳/链路时延监测 |
| 集群 | 登记/修改、维护、现有节点观测与队列/公告 | 新集群没有节点不会执行；没有新增节点或真实资源采集界面 |
| 跨网 | 跨网场景、发送/回执节点、模拟失败与日志 | 不是实际网闸/总线传输，不提供真实端到端回执协议 |
| 即时对账 | 双边计数、差异与证据状态、后续证据核销 | 核销不修数据；没有复杂血缘分支口径分摊 |
| 盘点 | 窗口、复合键、同名字段、数量/SHA1、冻结历史和差异下载 | 周/月频次仅约定，未自动调度；不支持任意转义/所有类型组合 |
| 跨中心 | 左上入口正确禁用未配置中心 | 未真正加载万象/资源中心，也未共享其数据仓储 |
| 持久化/备份 | IndexedDB单根记录事务、版本校验、确认恢复、导入暂停 | 真实浏览器多标签事务尚未验收，不是服务端安全机制 |

本轮没有新增后端，没有更换为React Flow，也没有升级原有依赖声明。深海钴蓝视觉、任务详情、映射/执行、账单和全屏画布为第二轮的重点。
