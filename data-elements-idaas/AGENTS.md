# data-elements-idaas · AI 开发入口

## 当前后端开发边界（2026-09-29）

用户已确认整体设计并授权继续完成全部阶段。公安、广电、海渔、澄天现均使用所属应用的独立本地 `rm_user_t` 和 `accountSource=LOCAL`；原机构、角色、菜单和关联数据保留。真实绑定分别为 `baseline_ga_old`（MySQL）、`BASELINE_BEIJING_GD`（达梦）、`baseline_sea_fishery`（MySQL）、`chengtian`（MySQL）。控制库仍承担租户定义、数据库路由和共享 Magic/低代码资源；本地闭环不等于脱离控制库运行。

`baseline` 已部署 40 张目标 IAM 业务表。公安应用的人员、机构、角色和资源完成一次性正式初始化导入，原本地现状展示镜像表已退役。平台认证只查询 `iam_operator_t` 及独立凭据/安全表；`iam_subject_t` 是不默认具备登录能力的人员主档；`iam_auth_account_t` 属于独立的统一认证账号域。三者与应用本地账号隔离。平台功能权限及角色配对管理范围在 Magic 即时校验，平台会话不附带 tenantId。业务规则、SQL、幂等、审计、策略、目录、授权、公众身份和下发均在 `13.统一身份管理`；Java 只提供安全、会话、协议和显式数据源等框架原语。当前状态以 [手动同步实施记录](docs/同步改为手动执行20261001.md) 为准；此前 [后续阶段实施与验收](docs/后续阶段实施20260929/实施与验收说明.md) 及 JSON 保留历史验收证据。

统一身份管理平台不得在后台定时扫描人员权限、变更事件或下游同步任务。只有用户在“同步对象”点击下发，或在“同步任务”点击继续执行／重试时，才调用下发接口。修改目录和授权只保存本地资料及权限结果，不自动向租户系统推送。

公安接收端仅增加三张轻量 `idaas_receiver_*` 表用于信任、来源映射和幂等回执；不复制中央 IAM 业务表。本地账号维护和接收业务都在 Magic，中央撤权保留本地独立授权，中央启用不覆盖本地停用。实际四个行业应用仍为 LOCAL 认证、中央下发 OFF；不得以完成开发为由自动开启原应用的 SSO 或中央下发。

旧共享账号接口已退役，框架 `idaas.legacy-control-accounts.enabled` 默认 false，不自动绑定共享成员关系，也不以同名或同 ID 将平台身份映射为应用账号。历史表按私有备份和摘要归档保留；不得重新运行旧租户安装器、初始化器或完整发布器恢复已退役模型。平台增量发布使用 `data-elements/scripts/publish_idaas_foundation.py`，本地适配使用 `publish_ga_self_loop.py`。涉及恢复应先冻结相关写入并处理迁移后的新增数据。启动签名密钥须持久化，见 [启动配置与持久密钥](docs/后续阶段实施20260929/启动配置与持久密钥.md)。

## 产品与工程命名

英文工程名仍为 `data-elements-idaas`，仅用于目录、构建、包标识与工程文档；中文产品名“卓鉴”仅用于内部产品资料。所有用户可见页面、浏览器标题、登录品牌、说明、帮助与页脚只使用系统名称“统一身份管理平台”，不出现工程名或产品名。政企身份域与公众身份域共用同一系统名称，身份域名称只用于业务上下文。

左上角系统切换入口固定显示短名称“统一身份管理”及下箭头；桌面折叠时保留可点击图标，手机导航抽屉保留完整切换入口。切换列表沿用其他系统的五组分类，本系统归入“平台支撑”，列表项使用完整系统名称“统一身份管理平台”。各系统使用当前标签页跳转，开发地址使用 localhost 和独立端口，生产地址通过环境变量覆盖。

管理控制台采用固定的一套菜单，不恢复顶部政企／公众身份域切换，也不在侧栏品牌与菜单之间显示英文工程名或折叠后的产品分组标题。公众总览、自然人、法人、公众认证账号、身份核验、公众应用、公众应用分组及公众统计统一位于“公众身份”；平台角色、安全策略、品牌和审计共用原有入口。管理登录页不要求选择政企侧／公众侧，独立统一认证入口仍保留认证身份域选择。

菜单通过 `session.navigationPermissions` 的分域只读权限发现展示，不能将其并入当前操作权限或赋予登录其他系统的资格。页面路由自动加载所需工作区，未完成时隐藏旧域内容，拒绝时显示失败并允许重试；同域加载去重，不同域串行，旧会话响应不得覆盖新会话。菜单、搜索、帮助、手机导航采用同一入口清单。顶栏不再显示“平台账号”类别标识；当前登录人员及角色仍在右侧个人入口中展示。

桌面侧栏折叠后二级菜单支持悬停、点击及键盘打开，鼠标可移入弹层选择功能；选择或离开后关闭。折叠弹层与展开菜单分别维护状态，展开时保留当前功能所属分组；手机抽屉使用内联菜单，权限与管理范围过滤同展开侧栏一致。

运行期名称统一引用 `src/domain/branding.ts`。后端旧品牌标题或说明含旧产品名、工程名时，展示为系统名称；不改写业务名称、审计记录或原始数据库配置。不含这些名称的用户自定义标题保持原样。`iam.*` 浏览器存储键、CSS 类名与变量、对象 ID 属于兼容性标识，不因展示文案修改。历史测试日志、截图、文件清单和原始方案引用保留原始记录，不改写为当前验收证据。

应用详情将“人员”和“机构”作为两个独立页签，连续放在“角色”前面，不恢复“人员与机构资料”的嵌套页签。“运行绑定”不再占用独立页签；原应用与运行租户、本地权限标识的关联保留，在“概览”的默认折叠“应用连接信息”中查看及检查。页面称“租户库标识”和“租户内权限应用标识”，分别定位数据库及库内角色菜单；不显示大段说明横幅。保留原分配、授权和连接检查权限，不因页签调整创建本地账号或自动启用下发。

应用详情的客户端登记、回调及认证接入配置集中在末尾“接入配置”页签，不再重复显示“客户端”“认证设置”。应用本地人员、机构、角色、资源、授权用户从已核验的运行绑定只读查询；平台资料分配与平台授权分别标注来源，不能把本地角色或本地账号当成中央授权。公安首次导入只写控制库正式 IAM 表，使用 `iam_application_config_t` 的 `SYSTEM/initialTenantImport` 记录防重复标记，不再读取 `iam_application_t.ext_json`。租户后续新增资料不自动回流；仅在应用详情“资料同步”中人工查看差异并再次确认后，按所选项将人员、机构资料导入控制库。平台资料下发仍要求已配置且测试通过的接收端与人工确认，不自动执行。两个登录账号体系和授权始终隔离。

应用详情“人员”“机构”页的租户资料展示不显示大段来源提示。“刷新列表”仅重新读取该租户库，不执行导入或下发；平台分配表的“刷新分配”只重读控制库。业务表以“已分配／已移除”“已授权／未授权”展示资料与平台授权，保留下发状态，不展示期望／确认版本号。人员、机构页两张表的行距和操作尺寸比普通紧凑列表更舒展。

应用列表顺序只保存在控制库 `iam_application_t.sort_no`，卡片与表格共享排序，使用 Magic 的 `/idaas/applications/reorder` 显式保存；不修改租户库应用表。部署到其他环境时先执行 `V20261001_01__idaas_application_sort.control.mysql.sql`，再增量发布 `applications` 函数和 `/reorder` 接口。初始化顺序将公安元数据管理平台放在首位。列表四张统计卡片依次展示应用、角色、用户、权限；“平台账号”顶栏标识及应用页标题下的介绍文字已移除。

## 开始前

先完整阅读根目录 `design.md`，再看 `src/app/typography.ts`、`src/app/theme.ts`、共享组件和目标业务页。当前为 **V2.2 可读紧凑版**，不要重新套用 V2.1 的小字号规则。

## 不可回退

保持现有 Ant Design、深海蓝侧栏、白色卡片与蓝紫主题；管理工作区保持 compact 算法和 small 控件。登录、公众认证、注册及密码流程按用户要求使用独立 `authTheme`、标准算法及 large 表单：输入框 44px、主按钮至少 48px、字段间距 24px，不能再次压回紧凑高度。**密度不改变文字语义层级。** 页面24、面板18、卡片16、菜单/正文14、说明13、标注12px。指标28px另作数据角色。

不能给全部 Typography/所有 span 统一小字号；不能用全页缩放或裁切解决排版；不能让卡片标题里的 Text 覆盖成较小字号。SVG 标注须检查实际屏幕字号，不能只检查 viewBox 内的数字。

不恢复标准/紧凑开关、不恢复设计规范菜单/路由/搜索项/帮助入口。设计规范只在工程 `design.md`，不是产品功能。界面继续使用正常业务语言，不添加 Mock、演示、评审、模拟等研发措辞。不要为文案变化伪造服务端能力。

不得重置浏览器数据或改动授权并集、有效期、身份域和管理员业务隔离规则。除任务明确要求外，不升级依赖、不换 UI 库。

## 修改入口与检查

字号数值统一在 `typography.ts`；CSS 变量通过 `npm run tokens:generate` 生成。Ant Design 组件 Token 在 `theme.ts`；业务语义文字样式在 `typography.css`；密度/响应式主要在 `app.css`。

本地开发、构建预览和浏览器测试的默认地址统一为 `http://localhost:3005`，主机、端口与严格端口检查由根目录 `dev-server.config.ts` 维护。端口占用时应报错，不自动递增；其他系统的端口分配不随本工程调整。

完成后至少执行：

```bash
npm run tokens:check
npm run syntaxcheck
npm run audit:ui
npm run audit:typography
npm test
npm run typecheck
npm run build
npm run test:typography
npm run test:compact
```

`preview/index.html` 是独立 HTML 辅助，不是 React 产物。不得用它的截图证明 React 通过。若依赖或浏览器测试失败，记录实际原因，不写虚假的全部通过。
