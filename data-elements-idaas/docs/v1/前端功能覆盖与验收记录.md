# 卓鉴统一身份管理平台 · 前端功能覆盖与验收记录

> 项目：`data-elements-idaas`；产品：卓鉴；系统：统一身份管理平台。本文保留原版本的范围与验证结果，旧日志、截图、文件清单和原始方案名称仅用于历史追溯；当前命名及本次验证见 `../命名统一说明.md`。

版本：前端评审版1.0.0。记录日期：2026-09-26。基线：产品需求规格说明书V1.1，第15章为本轮交付边界。

## 一、完成口径

“已编写”表示对应页面和状态变更已存在于源码；“逻辑已测”表示在本次环境实际执行了领域/Mock适配器自动化测试；“浏览器待验”表示没有以目标框架安装后的实际页面完成验证。三者不混用。

本包不含后端。本次环境无法解析/连接npm下载依赖，因而无法完成目标依赖安装、正式全项目类型检查、生产构建或浏览器视觉验收；这不是已通过发布门禁的成品部署包。

| --- | --- | --- |
| A01 管理登录 | 登录表单、双域选择、错误提示、固定评审角色 | 仅Mock口令，不是OIDC登录；策略配置不改变测试账号 |

| A05 SSO结果 | 应用接入配置检查、公众本地登录结果及应用资格查看 | 没有真实回调、票据、全局退出；未完整制作协议错误码结果页 |

| G04—G06 角色/资源/用户 | 应用内角色与资源增改删、资源关联、有效用户与来源 | 未实现菜单资源的批量导入；部分批量效率操作后续补充 |

| G11 分级管理员 | 范围/人员配置CRUD；固定orgadmin检验基本范围 | 未实现动态多级委派、转授权链和撤销级联的全部界面 |
| G12 条线 | 条线记录CRUD | 条线继承计算、继承覆盖预览未实现 |
| G13—G14 字典与扩展 | 配置CRUD、查询、详情 | 字段类型为配置值；尚未实现动态校验和表单构建 |
| G15—G17 授权 | 三视角、对象选择、期限、原因、预览、撤销、有效来源与角色 | 核心有效权限逻辑已测；预览显示涉及人数，不是完整新增/失去/保留差异图；暂未提供专门的已有授权期限编辑页 |
| G18 权限组 | 多应用角色组合、成员、启停、删除、来源重算 | 核心重算和删除保留其他来源逻辑已测；无多级嵌套组 |
| G19—G20 API授权 | 应用/用户配置CRUD、API范围字段 | 不产生真实OAuth scope或后台执行权限 |
| G21 同步配置 | 目标、接口、对象、范围、映射说明、模式、超时配置 | 映射仅保存文本；“实时事件”只是配置项，未实现自动触发链 |
| G22—G23 同步对象 | 用户/机构切换、范围、最近状态、选择提交 | 实体列表的数据转换尚未执行 |
| G24—G25 同步任务 | 队列、进度、成功/失败明细、重试、中止 | 失败由固定规则模拟；保留轮次而非完整每轮快照；没有真实发送/回执 |
| G26—G28 审计统计 | 操作、登录、API列表、筛选、导出、前后快照、统计页 | 本地日志可被修改；无归档、防篡改、长期检索服务 |
| G29—G30 管理员/系统角色 | 管理配置CRUD；固定角色菜单与Mock写操作限制 | 新增配置不等于新增可登录账号；未实现任意动态权限矩阵执行 |
| G31—G34 安全/SSO/加密/API | 设置表单、校验、保存、重置、修改提示 | 不执行真实锁定计数、MFA、令牌、字段加密、IP限制或限流；脱敏展示使用固定前端规则 |
| G35 系统品牌 | 名称/副标题/Logo URL配置，标题即时更新 | 没有品牌文件上传服务；Logo仅为浏览器图片URL |
| G36—G37 解锁/个人中心 | 本地锁定状态解除、个人资料、改密表单 | 解锁不启用已停用用户；改密不修改真实凭据 |
| P01—P04 公众认证 | 自然人/法人登录、注册、验证步骤、密码流程 | CA、人脸、微信、支付宝未接入；注册不自动实名或授权 |
| C01—C09 公众管理 | 概览、应用、自然人、法人、关联与子账号、日志、系统配置 | 子账号为已有自然人关联；未做完整法人代理审核与子账号邀请激活流程 |
| UI通用 | Ant Design原生组件、统一Token、查询表格、抽屉、状态展示、响应式CSS | 无目标版本浏览器实测；离开设置页时未保存提示覆盖关闭浏览器，不覆盖所有路由切换；键盘/读屏/200%缩放需逐项验收 |

上述前端细节缺口不统一归因为“等待后端”：任职细分、批量效率、完整差异预览、动态角色编辑器等仍属于后续前端完善工作。请以本矩阵而非只看菜单数量判断覆盖程度。
