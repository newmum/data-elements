# 公安应用角色映射与新建用户联调

## 管理员操作

1. 在统一身份管理平台进入“组织与用户 → 组织与用户”，点击“新建用户”。填写账号、姓名和组织机构。
2. 勾选“同时添加应用授权”，选择公安应用、应用角色，并填写授权原因。角色下方可查看该角色的中央权限资源。
3. 勾选“保存后立即下发此用户”，选择标有“已映射本地角色”的公安接收配置，点击“保存”。同一次操作依次保存人员、应用授权、人员资料分配并执行单人下发。若后一步失败，抽屉保留已完成进度，可修正后重试，也可在“同步管理 → 同步任务”查看任务明细。
4. 公安本地管理员在“公安元数据管理平台 → 系统配置 → 用户管理”找到新账号，设置密码并启用。人员资料报文不含密码，也没有默认密码。随后新用户使用该账号和本地设置的密码登录公安系统；菜单来自绑定的公安本地角色。
