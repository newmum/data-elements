# 卓鉴统一身份管理平台：统一管理控制台

## 功能安排

管理后台可以合并为一套菜单。政企人员目录与公众身份具有不同的业务结构，公众管理适合成为左侧独立业务分组，包含业务资料管理和核验配置，而不只是一个开关。后台保留两类资料的身份域、功能权限及管理范围；合并的是管理入口和导航，不迁移人员、不合并密码、不扩大操作账号的权限。

侧栏品牌后的 `data-elements-idaas` 分组标题及折叠后的“卓鉴”分组标题均已删除。左上角“统一身份管理”及系统切换箭头保留。

顶部政企域／公众域切换及平台管理登录页的政企侧／公众侧选择已删除。控制台显示固定菜单；进入公众页面不会替换整套导航。原组织与用户、应用、授权、同步、审计和系统管理仍按权限显示。

| 左侧公众身份功能 | 页面地址 | 业务内容 |
| --- | --- | --- |
| 公众总览 | `/console/public/overview` | 公众身份及应用的统计 |
| 自然人管理 | `/console/public/persons` | 公众人员资料与实名状态 |
| 法人管理 | `/console/public/entities` | 法人资料、经办关系、关联子账号 |
| 公众认证账号 | `/console/public/auth-accounts` | 独立统一认证账号和凭据管理 |
| 身份核验 | `/console/public/verifications` | 核验渠道配置与申请结果 |
| 公众应用 | `/console/public/apps` | 公众身份域的应用 |
| 公众应用分组 | `/console/public/app-groups` | 公众应用分类 |
| 公众统计 | `/console/public/audit/statistics` | 公众身份域的访问统计 |

管理员、平台角色、全局安全策略、品牌和审计复用已有系统管理、审计入口；它们仍遵循服务端原有的政企管理范围校验。只有公众范围不自动获得这些平台配置权限。独立统一认证入口仍按认证账号的实际身份域登录，不改变平台操作账号、统一认证账号和应用本地账号的隔离。

## 顶栏账号类别

原绿色“平台管理”只是 `session.realm === 'platform'` 的显示结果，表示当前使用卓鉴平台操作账号；它没有查询运行环境或健康状态，也不表示该账号拥有所有管理权限。

现改为中性的“平台账号”，去除绿色状态圆点，鼠标悬停或键盘聚焦可查看说明。具体权限仍由角色与管理范围决定。

## 数据和接口变化

本次没有新增或修改数据库表、字段，没有修改公安等租户库，没有新增 Java 运行期业务或框架逻辑，也没有新增 HTTP 接口。

`13.统一身份管理` 的 Magic 会话函数 `@/idaas/session` 新增返回字段 `navigationPermissions`。其结构为按 `workforce`、`public` 分域的 `permissions` 和 `globalPermissions`，只包含已有角色及其配对管理范围允许的 `:read` 权限；强制改密时不提供业务菜单发现信息。

`/idaas/session/me`、`/idaas/workspace/bootstrap` 和 `/idaas/session/domain` 使用上述会话函数，原来的当前域操作权限、可写应用、机构范围和账号安全校验保持独立。菜单发现信息只用于展示入口，不能用作写入授权或换取租户会话。增量发布仅更新一个 Magic 函数，保留已有资源 ID、路径和其他接口；发布前保留私有备份，刷新运行资源后通过真实接口验证。

前端按目标页面路由加载所需身份资料。相同域请求去重，不同域请求串行；加载时遮住旧域内容，失败时显示原因并允许重试。刷新、深链接和浏览器后退支持自动恢复正确的资料上下文；退出或更换会话后，迟到响应不能恢复旧资料。桌面、折叠菜单、手机抽屉、搜索和帮助复用同一入口清单。

## 验收证据

真实接口结果见 [真实接口验收](真实接口验收.json)。真实页面结果、分辨率和截图见 [真实界面验收](真实界面验收.json)。最终检查结果在 [检查汇总](检查汇总.json) 记录，包括单元测试、Magic 语法及权限测试、菜单回归、排版与紧凑布局检查。

核验渠道仍需要实际服务配置。该修改提供统一管理入口，不会自动启用或填充外部核验服务，也不会将空的公众资料伪造为已核验记录。

共享后端在第一轮真实页面检查期间发生重启，导致一次返回政企工作区失败；当时的失败日志单独保留。服务恢复后重新执行真实页面检查，交付证据只采用实际通过的记录。重启导致原浏览器会话失效时，需要使用原平台操作账号重新登录。
