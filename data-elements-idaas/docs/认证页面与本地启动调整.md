# 卓鉴统一身份管理平台 · 认证页面与本地启动调整

日期：2026-09-27。工程：`data-elements-idaas`。

## 认证页面尺寸

登录表单原先继承管理端的 compact 算法及 small 尺寸，桌面输入框和按钮约 28px 高。按用户要求，登录、公众认证、自然人/法人注册、找回密码和二次验证共用独立的舒展认证主题。管理工作区继续使用原有紧凑主题。

| 项目 | 原规则 | 当前认证页规则 |
| --- | --- | --- |
| 输入框 | 28px | 44px |
| 主要提交按钮 | 28px | 至少 48px |
| 身份域选择 | 约 28px | 约 40px |
| 字段下间距 | 12px | 24px |
| 标签下间距 | 4px | 8px |
| 标签文字区域 | 随大号 Form 继承控件高度 | 按正文 22px 行高排布 |
| 标题、表单正文 | 24px、14px | 保留同一文字层级 |

`AuthFrame` 局部使用 `authTheme` 和 Ant Design 标准算法，Form、Tabs 使用 large 尺寸。主按钮、标签和响应式间距限定在认证页面范围内。手机不缩小输入框与主按钮，长注册表单、矮窗口允许正常纵向滚动，保留全部操作入口。认证页浏览器标题随当前品牌名称更新。

主题入口为 `src/app/theme.ts`，布局为 `src/styles/app.css`，文字和标签行高为 `src/styles/typography.css`；对应独立 HTML 辅助预览已同步。后续开发约定已写入 `AGENTS.md` 和 `design.md`。

## localhost 与端口分配

原 `dev`、`preview` 命令显式使用 `--host 127.0.0.1`，开发端口为 5173。现在由 `dev-server.config.ts` 统一维护：

- 主机：`localhost`。
- 端口：`3005`。
- 登录入口：`http://localhost:3005/#/login`。
- `strictPort: true`：端口占用时报错，不自动切换端口。
- Vite 开发、构建预览、Playwright 的服务与 baseURL 共用同一配置。开发与构建预览使用同一端口，运行时选择其中一个。

检查同目录工程当前环境配置：数据中台为 3000、启智为 3001、海通为 3002、设计器为 3003、报表为 3004。未发现 3005 被分配，调整前也没有服务监听该端口。已重启卓鉴自己的旧开发进程，新服务日志显示 `http://localhost:3005/`；数据中台与启智的原监听进程保持原样。

不同主机名和端口属于不同浏览器存储来源。旧 `127.0.0.1:5173` 来源的数据仍保留，没有删除或重置；首次切换到新地址需要重新登录。业务对象 ID、授权、审计与自定义品牌的兼容规则沿用命名统一说明。
