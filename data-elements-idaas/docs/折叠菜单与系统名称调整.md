# 卓鉴统一身份管理平台 · 折叠菜单与系统名称调整

日期：2026-09-27。工程：`data-elements-idaas`；产品：卓鉴；系统：统一身份管理平台。

## 行为调整

原来桌面侧栏收起后，`Shell.tsx` 将受控菜单的 `openKeys` 固定为空，导致鼠标悬停无法打开二级菜单。现在折叠弹层使用独立状态，保留 Ant Design 的悬停与键盘事件，同时点击图标也能打开对应分组。

- 鼠标悬停或点击应用管理、组织与用户、授权管理、同步管理、审计日志、系统管理，均可打开二级功能。
- 鼠标可以从图标移入弹层；选择功能后跳转并关闭弹层，侧栏保持折叠；移出菜单后关闭。
- 键盘方向键可进入二级菜单，Enter 可选择功能。
- 展开侧栏仍使用内联菜单；手机抽屉独立渲染内联菜单。身份域和角色过滤继续复用原有业务规则。
- 弹层使用导航字号 14px，采用深海蓝菜单样式，限制高度并支持内部滚动。

系统切换弹框中的卓鉴入口改为“统一身份管理平台”，位于“平台支撑”。左上角展开后的按钮仍显示短名称“统一身份管理”与下箭头。万象治理及磐石/皓月共用切换器、启智共用切换器、海通和数据中台“全部导航”同步显示完整系统名称。地址与跳转方式沿用已有配置。
