# 公安租户账号自闭环实施与验收

日期：2026-09-28。目标系统为公安元数据管理平台，现有页面品牌为“源数据管理平台”。共享后端继续使用 `data-elements`，控制库为 `baseline`，公安实际绑定库为 `baseline_ga_old`，租户 ID 为 `2084109831682699264`。本次根据用户最新要求，只落实公安本地用户管理闭环。

## 表位置与实施结论

实施前核查结果：`rm_user_t` 和 `rm_user_tenant_rela_t` 都在控制库 `baseline`；公安库在此前回退后没有本地用户表。公安库已有机构、角色、菜单、用户机构、用户角色和角色菜单关系。如果账号及密码仍从控制库读取，新建、修改、停用用户仍会依赖共享账号语义，不能形成公安本地账号管理闭环。

因此，本次在公安库建立最小 `rm_user_t`，一次性复制控制库中具有有效公安成员关系的 5 个未删除账号；保留原用户 ID、资料、状态及加盐密码摘要。原账号密码继续有效，已有机构与角色关联不必重建。迁移后公安运行期不再从控制库读取或修改账号，也不会在找不到本地账号时回退查询控制库。控制库原账号和成员关系没有删除或修改，以免影响其他尚未改造的租户与卓鉴现有功能。

`rm_user_tenant_rela_t` 不迁入公安库：该表用于共享账号跨租户成员关系；公安本地账号只属于当前公安租户，用户机构、用户角色关系已足以维护本地系统。不能为了历史机构关系中的用户 ID 自动创建账号或授予登录资格，原有历史关联行保持原样。

新表的完整结构见 [rm_user_t.schema.sql](../../data-elements/db/migrations/resources/ga-self-loop-20260928/rm_user_t.schema.sql)。该文件是已部署结构快照，不包含账号资料或密码，可用于审阅，不能直接用于覆盖现有本地用户。

## Magic API 业务实现

外部接口保持现有页面契约。公安 LOCAL 分支负责本地业务；其他 CONTROL 租户保留原分支。现有 API 的来源文件清单见 [resource-manifest.json](../../data-elements/db/migrations/resources/ga-self-loop-20260928/resource-manifest.json)。共适配 41 个现有业务脚本，含登录、账号查询维护、角色菜单、在线会话，以及读取当前会话属性的文件和流程接口。

新增完整函数组 `/magic-api/function/09.租户账号/`：目录行、`group.json` 与 5 个函数行完整注册，运行期路径为 `/tenant-account`。这属于租户本地系统业务；卓鉴中央业务仍位于 `13.统一身份管理`，本轮没有新增中央下发功能。

| 函数 | 实现的业务 | 来源 |
| --- | --- | --- |
| `/tenant-account/login` | 验证本地账号、状态及加盐密码，建立本地会话并记录登录日志 | [login.ms](../../data-elements/db/migrations/resources/ga-self-loop-20260928/login.ms) |
| `/tenant-account/users` | 本地分页、列表、新增、修改、密码变更、停用和删除；维护主要所属机构 | [users.ms](../../data-elements/db/migrations/resources/ga-self-loop-20260928/users.ms) |
| `/tenant-account/roles` | 按当前应用维护本地用户角色，保留其他应用关联 | [roles.ms](../../data-elements/db/migrations/resources/ga-self-loop-20260928/roles.ms) |
| `/tenant-account/role-admin` | 本地角色新增、修改、删除及有效本地用户关联 | [role-admin.ms](../../data-elements/db/migrations/resources/ga-self-loop-20260928/role-admin.ms) |
| `/tenant-account/resources` | 校验同应用有效菜单资源后，在事务中替换角色菜单关联 | [resources.ms](../../data-elements/db/migrations/resources/ga-self-loop-20260928/resources.ms) |

用户及主要机构关联、角色用户关联、角色菜单关联分别在同库事务中维护。无效机构、用户、角色、菜单或重复账号返回失败，不覆盖原有效关联。查询返回密码占位符，不返回存储摘要；密码变更、停用、删除后清理所属本地账号会话。当前维护账号不能删除、停用或移除自身的必要角色。停用角色不再提供应用权限。

Magic 编辑器仍为 `http://localhost:8088/api/web/index.html`。实际运行资源存储在 `baseline.api_file_t`；修改本地 `.ms` 文件本身不会自动发布到数据库。可在编辑器中查看和保存业务脚本，也可用增量发布脚本显式部署后调用现有资源刷新接口；无需为业务脚本修改重新编译 Java。

## Java 框架改动

以下逻辑写在共享后端框架层，修改后需要重新构建并启动后端：

- `TenantAccountPolicy` 从显式控制数据源读取租户账号模式，并要求 LOCAL 租户具有有效、显式的业务数据源绑定；配置错误或本地库不可用时失败，不回退控制库。
- `TenantSessions`、`TenantAccountsMagicModule` 管理本地令牌属性和会话失效。账号验证及业务写入仍在 Magic 中。公安使用 `tenant-local-v1` 标记和独立设备标识，本地属性存入 token session，避免覆盖同 ID 的原控制账号会话。在线会话扫描会先把 Sa-Token 存储键转换为实际令牌值，停用或改密只清理该租户的本地会话。
- `TenantWebInterceptor`、`TenantController` 校验请求会话与租户账号模式，限制公安本地会话只能访问公安；控制账号不能直接切入公安。公开登录、租户选项与登录设置先进入公开控制上下文，携带旧 token 也不触发本地账号检查。
- `TenantIdentityQueryService` 及目录、审批适配根据当前服务器租户上下文选择账号查询来源。公安读取本地表，未改造租户使用原控制库服务；框架层没有新增用户 CRUD 业务。审批会话读取同步使用上述适配。

当前用户可能在控制库和公安库具有相同的迁移 ID，但登录凭据、维护操作和会话作用域独立。后续修改公安密码不会修改控制账号密码。卓鉴继续使用独立 `idaas-platform` 平台会话，不能拿其令牌登录或操作公安系统。

## 已执行验收

实际接口请求及数据断言共 **110/110 通过**，其中 76 次 HTTP 请求、34 项数据/状态断言。使用唯一命名临时用户、机构和角色完成以下闭环，随后通过接口删除并清理这些测试记录，不修改已有业务账号密码：

1. 原公安账号以原密码登录，返回 LOCAL 公安上下文；原机构、角色和菜单有效，分页为 5 个业务账号，密码摘要不外泄。
2. 新增和修改机构、新增本地用户并绑定机构，按机构查询用户；新增账号不进入控制库，不生成控制库成员关系。
3. 新增角色、关联本地用户、从用户页面保存角色、保存菜单权限；新用户登录后实际获得对应机构、角色和菜单。角色停用后权限失效，重新启用后恢复。
4. 重复账号、无效机构、非本地用户、无效角色和菜单全部拒绝；失败的角色或菜单更新保留此前有效关联。
5. 在线列表正确显示本地用户；修改密码后旧密码和旧令牌失效，新密码成功。停用、恢复、删除用户及令牌失效通过，禁止删除当前维护账号。
6. 公安本地账号不能切换其他租户、不能登录卓鉴，公安令牌不能调用卓鉴会话；卓鉴令牌和其他 CONTROL 租户令牌不能进入公安。
7. 广电、海渔、澄天原账号登录及 CONTROL 上下文回归通过；4 个租户的公开登录设置在携带旧控制 token 时仍成功。此前暂停的中央下发继续返回 503。
8. 清理测试记录后，控制库全部用户和全部成员关系与迁移前完整记录一致；公安原有 7 张系统表的全部记录及完整建表结构一致；5 个迁入账号的 ID、全部原资料、状态和密码摘要与迁移前记录一致；本地保留 5 个有效业务账号，IAM 租户表数量为 0。

Java 框架与实际 Magic 引擎编译回归 **87 项通过**，包括 46 个业务脚本编译、查询来源隔离、账号配置、令牌键转换、拦截器、公开接口白名单、已有身份基础模块和包架构检查。后端已重新打包并启动，运行 JAR 包含 Lettuce 依赖。启用冷启动诊断后确认 `rootFunctionDirs` 包含 `function/09.租户账号/`，`rootTaskDirs` 正常，`missingFileGroups=[]`；冷启动后当前租户、当前用户、用户分页、机构、角色、菜单 6 个代表接口再次通过。

已在浏览器显式选择“公安行业场景”，以原账号登录并进入系统管理，确认“源数据管理平台”、科信总队上下文和 5 个本地用户。前端与低代码页面源码未改动，本次验收不以 React 前端测试代替后端测试。

验收明细见 [验收结果.json](公安账号自闭环验收/验收结果.json)，页面证据见 [用户管理截图](公安账号自闭环验收/用户管理.jpg)。接口测试脚本为 [verify_ga_self_loop.py](../../data-elements/scripts/verify_ga_self_loop.py)，默认执行完整闭环；`--finalize` 仅对已完成且已清理的最新接口记录补做只读原数据对比，不重建测试数据。

这里的自闭环指公安账号、密码、机构、角色和菜单授权由公安本地系统维护，运行期不要求卓鉴身份服务或中央下发。控制库仍存在并承载租户定义、共享 Magic 和低代码资源；本阶段不承诺控制库断线后继续运行。

访问地址为 `http://localhost:3000/#/login`。已有公安控制账号旧会话需要退出后重新登录；公开登录设置不受旧会话影响。其他租户库仍未改造，控制库现有用户的卓鉴专用隔离及中央标准接口下发继续留待后续单独实施，本次没有宣称这些阶段已经完成。
