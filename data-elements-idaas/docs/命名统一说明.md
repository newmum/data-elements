# 统一身份管理平台 · 命名统一说明

现行界面约定：2026-09-30。工程：`data-elements-idaas`。原 2026-09-27 验证记录保留在后文。

| 用途 | 统一名称 |

政企身份域与公众身份域属于同一系统，身份域、管理端和认证中心的业务名称保留各自语义，共用系统名称。界面不展示产品名或工程名。

## 修改范围

- `README.md`、`AGENTS.md`、`design.md` 区分内部工程标识与用户可见系统名称；运行期名称由 `src/domain/branding.ts` 维护。
- `package.json` 的包名保持不变，描述及入口 HTML 的浏览器标题与页面描述使用系统名称。
- 管理端、公众端、总览、认证页面、帮助与页脚都只显示系统名称；独立 HTML 辅助预览同步更新。
- Markdown 与 Word 需求规格同步更新封面、产品定位、退出提示及命名约定，Word 文件属性中的标题、主题与关键词同步更新。
- 版本文档补充当前工程和产品命名，并明确其历史范围。原始测试日志、截图、资源文件名、校验清单及来源方案名称保持可追溯。

## 数据兼容

展示名称调整不改变用户、应用、组织、授权、同步和审计的对象 ID、数据范围或业务规则；`iam.*` 浏览器存储键、CSS 类名和变量继续作为兼容性标识。

加载旧版数据时，品牌标题或登录说明含旧产品名、工程名的展示为系统名称，不写回数据库。其他自定义标题保持原样；业务资料与审计前后快照不改写。

## 2026-09-27 历史验证记录
