# 后端启动配置与持久签名密钥

> 本页记录当时的实施过程。下方 `D:\Sourcecode\data-elements-parent\data-elements` 是历史检出路径；当前仓库的后端目录为 `data-elements-parent/`，且当前 Git 树不包含所示 `initialize-idaas-protocol-key.ps1`。请勿直接照搬历史命令作为当前部署步骤。

认证协议使用 RSA 私钥签发 OAuth2/OIDC 令牌。它属于 Java 协议框架配置，账号、应用、授权、策略和下发业务仍在 Magic API 的 `13.统一身份管理`。

## 本次启动异常及修正

`identitySigningKeys` 抛出“请配置 IDAAS_PROTOCOL_JWK_FILE”说明应用没有读取到持久签名密钥的位置。原实现的 `@Value` 只查 `idaas.protocol.jwk-file`，提示的环境变量没有显式映射。本次同时支持以下配置，按顺序取值：

1. Spring/Nacos 配置 `idaas.protocol.jwk-file`。
2. 环境变量 `IDAAS_PROTOCOL_JWK_FILE`。
3. 当前运行账号的 `${user.home}/.data-elements/idaas/keys/protocol-signing.jwk`。

不存在、不可读、公钥文件、缺少稳定 `kid`、非签名用途或不兼容 RS256 的密钥均在启动时明确报错。应用不会在每次启动时自动生成密钥。当前本机已经将原测试环境 RSA 私钥原样导入稳定目录，密钥及 `kid` 未轮换。

已有密钥的首次导入方式：

```powershell
cd D:\Sourcecode\data-elements-parent\data-elements
.\scripts\initialize-idaas-protocol-key.ps1 -ImportFile '已有私钥的绝对路径.jwk'
```

全新部署没有旧令牌时，执行一次初始化：

```powershell
.\scripts\initialize-idaas-protocol-key.ps1
```

脚本生成 3072 位 RSA 私钥，限制目录权限为当前账号与 SYSTEM，并拒绝覆盖已有文件。私钥不进入 Git、Magic 脚本、业务数据库或日志。部署账号必须有读取权限；Windows 服务账号与当前桌面账号的默认目录可能不同，应指定明确位置。

自定义位置的正常启动方式：

```powershell
$env:IDAAS_PROTOCOL_JWK_FILE = 'D:\ServiceSecrets\idaas\protocol-signing.jwk'
java -jar .\target\data-element.jar
```

也可以在 IDE Run Configuration 中添加该环境变量，或在 Nacos 中配置 `idaas.protocol.jwk-file`。该值是文件路径，必须存在于后端运行主机上。当前工作区的 `.runtime/start-data-element-runtime.ps1` 已采用稳定默认目录并尊重显式环境变量。普通重启、重新打包及发布均复用这个文件；多实例使用同一密钥及 `kid`。密钥轮换应单独安排有效期和公钥发布兼容，不能直接覆盖文件。

## 其他关联配置

`IDAAS_TRANSPORT_KEY` 是另一把独立的 32 字节 Base64 主密钥，用于加密下发连接密钥、MFA 等私密配置。它不是 RSA 签名文件，也不能用已有用户密码替代；已写入密文的环境必须继续使用原主密钥。本次没有更换它。

本地 HTTP 调试可显式配置 `IDAAS_TRANSPORT_ALLOW_LOCAL_HTTP=true`、`IDAAS_PROTOCOL_SECURE_COOKIE=false`；正式 HTTPS 部署保留默认安全值。两者现已显式支持提示中的环境变量名。

本次重启还定位到 Nacos 的 `403 unknown user`，其前置客户端日志为登录请求连接／读取超时，不能据此断定密码错误；其后“datasource url 未配置”属于配置未加载的结果。启动所需 Nacos 连接凭据只能在本地引导配置或环境变量里提供，不能放到尚未能读取的远程配置中。本工程 `application.yml` 现显式将 `NACOS_USER` / `NACOS_PASSWORD` 同时映射到 `spring.cloud.nacos.config` 和 `spring.cloud.nacos.discovery`，使配置加载和服务发现使用一致的已配置账号。若仍报错，应同时检查配置中心连通性及客户端登录日志。
