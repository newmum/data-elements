# 卓鉴统一身份管理平台 · V2 Mock 数据与联调说明

> 项目：`data-elements-idaas`；产品：卓鉴；系统：统一身份管理平台。本文保留原版本的范围与验证结果，旧日志、截图、文件清单和原始方案名称仅用于历史追溯；当前命名及本次验证见 `../命名统一说明.md`。

## 一、组成与关联

初始数据：241个身份（180业务人员+1平台管理身份+60自然人）、12机构、12应用、24应用角色、48应用资源、271授权来源、3权限组、5同步配置、3同步任务、1800条日志、8法人、44条分类配置。

`domain/seed.ts` 保留上一版核心ID和结构，调用 `domain/premium-seed.ts` 补充业务场景。相同初始化时间会产生相同的数据内容；实际启动时采用初始化当天为日期基准。所有人员、机构、联系人与日志为虚构样例，不代表真实客户或线上指标。

业务链路：机构 → 用户主职/兼任 → 应用 → 角色 → 菜单/按钮资源；直接授权、机构授权、权限组授权叠加为有效权限。日志关联账号和应用；法人关联公众人员；任务关联同步配置和目标对象。全局页面的不同身份域均按范围过滤。

展示用身份类型 employee / partner / temporary 与账户状态 enabled / disabled、锁定 locked 是独立维度。应用人数为当前有效访问去重人数；授权条数为来源记录数，两者不能等同。某用户可以同时从两个来源得到同一应用资格，只计算一个可访问应用。

## 二、可评审场景

| 场景 | 入口和预期 |
| --- | --- |
| 正常/停用/锁定人员 | 组织与用户：状态和身份类型分开；锁定不等于停用 |
| 多来源授权 | 用户授权：选林若安等样例，查看直接、机构、权限组来源；撤销一种不覆盖其他来源 |
| 即将到期与过期 | 授权台账：统计与有效访问根据当前时间分别计算 |
| 无角色访问资格 | 配置授权：不选角色可仅授予应用访问，不产生业务资源权限 |
| 平台身份隔离 | 平台管理身份不会从直接、机构或权限组获得业务访问 |
| 多应用/不同接入 | 应用列表和详情：检查状态、负责人、角色和资源数 |
| 同步失败与重试 | 同步配置执行 → 同步任务明细 → 对失败项重试；查看计数与轮次 |
| 异常日志 | 审计中心按失败、高风险样例规则筛选；失败记录前后内容一致 |
| 公众法人关系 | 法人详情：经办人、关联人员、子账号、认证样例状态 |
| 失败可恢复 | 顶栏帮助 → 检查操作失败状态 → 下次Mock写入失败，再次保存 |
| 重置 | 帮助 → 恢复初始Mock，只清除v2修改，不删除v1数据 |

“风险”等级只是样例分类规则，不是检测引擎输出；身份已核验标记只是已准备的数据样例，注册操作不会自动产生实名证明。MFA开关是配置状态，不能替代真实认证。

## 三、存储与升级

业务数据键：`iam.frontend.mock.v2`；会话键：`iam.frontend.session`。v2使用独立数据键，避免旧版52个身份和旧数据结构影响新版首次体验。没有自动迁移v1业务修改；需要保留的旧资料应另行备份，不能在不知道其有效性的情况下静默合并。

完整初始JSON低于4MiB，测试对此设有断言；日志最多保留4000条。浏览器配额不足会显示警告；此时修改可能只保留于内存。不同浏览器不共享数据，本轮不实现跨终端同步；单标签页Mock不是协同数据库。

独立 `visual-preview.html` 内含一次种子快照，它不会自动跟随React工程里的编辑或系统日期更新。不要用预览文件数据持久化测试代替React Mock测试。

## 四、前端读写接口

`mock/database.ts` 导出 `getDatabase`、`setSession`、`resetData`、`setFailure`、`tickTasks` 与 `api`；`mock/store.ts` 将订阅连接到 React `useSyncExternalStore`。常用动作：`api.save`、`api.remove`、`api.login`、`api.recordEvent`、同步提交/重试/中止、公众注册及设置保存。表单捕获DomainError并保留输入。

`domain/engine.ts` 负责本地约束、有效授权、管理范围和任务状态计算；`domain/csv.ts` 负责CSV引用/转义。保存包含乐观版本检查；某来源撤销后重新计算所有有效来源。以上用于评审和接口契约说明，不是可信服务端授权实现。

## 五、真实后端接入要求

后端应提供认证会话、统一响应与分页、角色和资源校验、数据域隔离、审计、密码与MFA处理、授权事务、真实同步任务。以接口适配层替换本地实现，不直接把localStorage数据当作可信请求上下文。禁用账户、权限变更、访问控制均必须服务端校验。

表格与图表需明确计数口径、时区和时间范围；业务统计不可继续用前端初始样本当作线上数据。日志的设备、地点、请求耗时和风险结论必须来自对应服务，不得将当前样例字段保留为生产事实。
